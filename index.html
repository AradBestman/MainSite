01 — About

A developer who likes to finish what they start

I build for the web with HTML, CSS and JavaScript at the core, and reach for React, Node and TypeScript when a project calls for it. Most of the work on this site is exactly that: landing pages built from scratch, and small browser apps — a calculator, a memory game, a Pokédex pulling live data from an API — each one built to actually work, not just look finished.

I care about clean structure as much as visual polish: semantic markup, readable CSS, and JavaScript that does only what it needs to.
